Use your team's model

Add a model from your team, test it, then choose a side.

  1. Copy the model folder

    Put the folder in models/, next to app.py. Include model.json, the code and any weights.

  2. Refresh and test

    Click Refresh list below, then Test next to your model.

  3. Choose a side and play

    Close this window. Pick the model for Red or Black, then click Play.

For model authors

Start with models/team_template. Give your model a new ID in model.json.

Load weights in Policy.__init__. In select_move, return a valid move or action ID. See MODEL_API.md for the full guide.

Use a Python environment with your model's libraries. The included Python has no PyTorch. A weights file alone is not enough.

The demo models are not trained. Train your model separately, then add it here.

Game rules

Use normal Xiangqi moves. You lose if you have no safe move, even if your King is not in check.

A draw happens when the same board and turn appear three times, or after 120 moves without a capture. One move means one turn by Red or Black.

The move limit stops the game. This is not counted as a draw.

These are simple rules for our project. Full match rules for repeated checks and chases are not included.
